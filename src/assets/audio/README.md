# Sound clips go here

Drop audio files (`.mp3`, `.ogg`, `.wav` or `.m4a`) into this folder, named after a sound slot, then rebuild (`npm run build`) or restart `npm run dev`.

Examples: `music.mp3`, `whisper-1.mp3`, `whisper-2.mp3`, `giggle.mp3`.

What each slot is for, and what to search for: see [docs/SOUNDS.md](../../../docs/SOUNDS.md).
A file whose name does not match a slot is ignored, with a warning in the browser console.
